# Matriz de Gargalos Comerciais

## Objetivo

Transformar o diagnóstico em prioridade. A matriz ajuda a identificar qual gargalo deve ser atacado primeiro.

---

# Como usar

Dê uma nota de 0 a 3 para cada gargalo:

- **0:** não é um problema relevante agora.
- **1:** existe, mas não trava muito.
- **2:** trava com frequência.
- **3:** é um gargalo crítico.

Depois, escolha no máximo 2 prioridades para trabalhar na imersão.
