# Checklist de Preparação - Módulo 0

## Objetivo

Garantir que o aluno entre no workshop com clareza mínima sobre o negócio, a oferta atual, os clientes, os canais e os gargalos comerciais da software house.

Este checklist não precisa estar perfeito. Ele serve para tirar a operação do campo da impressão e colocar os dados básicos na mesa.

---

# 8. Critério de prontidão

Você está pronto para começar o workshop se conseguir responder:

1. O que vendemos hoje?
2. Para quem normalmente vendemos?
3. De onde vêm as oportunidades?
4. Onde as oportunidades travam?
5. Qual oferta queremos priorizar?
6. Qual tipo de cliente queremos atrair mais?
7. Qual tipo de cliente queremos parar de aceitar?

Se alguma resposta estiver incompleta, tudo bem. Ela vira pauta de trabalho no workshop.
