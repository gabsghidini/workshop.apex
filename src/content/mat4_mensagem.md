# 2. Estrutura da mensagem

Toda mensagem precisa ter:

1. contexto;
2. hipótese de dor;
3. motivo da conversa;
4. pergunta leve;
5. ausência de pressão.

---

# 3. Mensagem outbound

Use quando for abordar uma conta ou decisor diretamente.

```text
[Nome], vi que a [Empresa] atua com [contexto/segmento].

Normalmente, quando [situação do ICP], é comum aparecer [dor/gargalo].

Não sei se isso acontece por aí, mas queria entender: hoje [pergunta leve sobre a dor]?
```

# 7. Teste de qualidade

Antes de usar, marque:

- [ ] A mensagem fala com um ICP claro.
- [ ] Existe uma hipótese de dor.
- [ ] A mensagem não vende o projeto cedo demais.
- [ ] Existe uma pergunta simples.
- [ ] O texto não parece spam.
- [ ] O lead certo se identifica.
- [ ] O lead errado tende a se autoexcluir.
