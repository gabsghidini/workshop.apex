# Upsell Pós-Imersão — Abertura para o Acompanhamento Pago

## Momento de uso

Após o fechamento do Módulo 6 (Plano de Execução de 30 Dias), ao final do Dia 2.

O aluno já:

- recebeu o diagnóstico de maturidade comercial;
- preencheu o plano de execução de 30 dias;
- identificou em qual estágio está;
- definiu o próximo passo dentro da imersão.

Agora ele está no ponto mais receptivo da jornada: tem clareza do problema, tem o sistema montado, e sente que o trabalho de verdade começa agora.

---

## Objetivo do upsell

Apresentar os caminhos de continuidade com a APEX de forma direta, honesta e sem pressão.

Não é pitch de produto. É diagnóstico de encaminhamento.

O aluno precisa sair sabendo:

> "Sei o que a APEX oferece, para quem cada coisa faz sentido, e qual é o meu próximo passo."

---

## Estrutura do script de upsell

### Abertura — Reconhecimento

```
Você fez isso.

Dois dias. Sistema comercial montado.

ICP. Oferta. Mecanismo. Canais. Pipeline. CRM. R1. Follow-up. Plano de 30 dias.

Isso não é pouco. A maioria das software houses passa anos sem ter clareza sobre metade do que você construiu aqui.

Agora vem a parte que ninguém conta na página de vendas do workshop:

A imersão não é o fim. É o começo.

O começo funciona quando existe execução. Sem execução, o material vira um arquivo bonito.

Então vou ser direto com vocês sobre o que a APEX oferece depois daqui — e para quem cada coisa faz sentido.
```

---

### Caminho 1 — Execução Sozinho

```
O primeiro caminho é executar sozinho.

Você tem tudo aqui. Os materiais, o plano, o sistema.

Se você tem disciplina de rotina, tempo para executar e já sabe com quem vai contar internamente, isso pode ser suficiente.

O que vai determinar se funciona:

— Se você revisar o pipeline toda semana.
— Se você ajustar a mensagem com base no feedback, não na intuição.
— Se você conduzir a R1 como diagnóstico, não como apresentação.
— Se você não pular etapas quando a agenda encher.

Se você marcar tudo isso como verdade, execute sozinho por 30 dias.

Se travar, volte para a gente.
```

---

### Caminho 2 — Sistema Comercial Assistido

```
O segundo caminho é o Sistema Comercial Assistido.

Para quem ele faz sentido?

Para quem terminou a imersão, tem a base montada, mas sabe que vai precisar de um olho externo para não desviar.

O formato funciona por milestones — não por sessões fixas.

Cada sessão com a APEX é desbloqueada quando você entrega um marco real:

— Primeiro marco: 20 abordagens feitas.
— Segundo marco: primeira R1 realizada.
— Terceiro marco: 3 leads em follow-up ativo.
— Quarto marco: primeiro resultado concreto.

Isso garante que a gente só avança quando a operação está se movendo.

Você não paga por sessão. Você paga por um período de seis meses com acesso a quatro sessões estratégicas desbloqueadas por você mesmo.

Para quem quer executar, mas não quer executar no escuro.
```

---

### Caminho 3 — CAÇADA

```
O terceiro caminho é o CAÇADA.

O CAÇADA não é consultoria. É execução.

A APEX monta o sistema comercial e opera o tráfego pago. Você recebe leads qualificados, conduz as reuniões e fecha.

Para quem faz sentido?

Para quem saiu da imersão, tem uma oferta validada, tem alguém que consegue conduzir R1 e fechar, e quer que a APEX gere o fluxo de inbound.

Para quem o gargalo não é processo — é volume de leads chegando.

O CAÇADA não resolve uma oferta confusa.
O CAÇADA não substitui quem fecha.

Ele resolve o volume de inbound qualificado para quem já tem o resto funcionando.
```

---

### Caminho 4 — CAÇADA PRO

```
O CAÇADA PRO é para quem quer os dois motores rodando.

Além de tudo que o CAÇADA entrega — sistema e tráfego pago — o CAÇADA PRO adiciona um SDR parcialmente dedicado fazendo prospecção ativa.

Inbound chegando via tráfego. Outbound acontecendo via SDR.

Para quem faz sentido?

Para quem já tem o inbound funcionando ou validado, quer adicionar um motor de prospecção ativa sem montar time interno, e tem capacidade de fechar o volume maior de reuniões que vem dos dois lados.

Se o seu gargalo é maximizar volume de pipeline sem montar estrutura interna de SDR, o CAÇADA PRO é o caminho.
```

---

### Caminho 5 — PREDADOR

```
O PREDADOR é o nível máximo de execução da APEX.

BPO comercial completo.

A APEX opera tudo: sistema, inbound via tráfego pago, outbound via SDR dedicado exclusivamente à sua conta.

Você só precisa fechar.

Para quem faz sentido?

Para quem tem um closer forte, um produto com escala de receita que sustente o investimento, e quer terceirizar completamente a geração de pipeline.

Não é para quem está começando. É para quem já comprovou que tem capacidade de fechar e precisa escalar o volume de entradas.
```

---

### Fechamento — Encaminhamento honesto

```
São cinco caminhos.

Nenhum é melhor que o outro. Cada um faz sentido para um estágio diferente.

Agora vou fazer uma coisa simples.

Vou dar um tempo para vocês preencherem o diagnóstico de maturidade — se ainda não fizeram — e ao final, quem quiser conversar sobre o próximo passo específico para a sua empresa, pode me chamar agora ou me mandar mensagem nos próximos dias.

Não tem pressão. Não tem prazo artificial.

Se a imersão fez sentido, o próximo passo vai aparecer com clareza quando você sentar para olhar o diagnóstico de verdade.

Obrigado por esses dois dias. Isso aqui foi feito com vocês, não para vocês.

Agora vai executar.
```

## Objeções comuns e respostas

### "Deixa eu executar sozinho primeiro e depois eu vejo."

```
Faz todo sentido. Você tem o sistema. Se executar com disciplina, vai gerar resultado.

O que eu pediria é que você não deixasse passar mais de 30 dias sem olhar os números. Se em 30 dias os indicadores não estiverem se movendo, não espere 60 ou 90 para chamar a gente.

O Sistema Comercial Assistido existe exatamente para esse momento.
```

---

### "Ainda não sei se minha oferta está validada."

```
Então você não está pronto para CAÇADA ou PREDADOR — e eu prefiro ser honesto sobre isso.

O Sistema Comercial Assistido faz sentido aqui: a gente vai lapidar a oferta junto, com milestones reais, até que você tenha clareza suficiente para saber se o próximo passo é tráfego ou não.
```

---

### "Qual é o valor dos programas?"

```
Os valores variam por programa e por configuração específica para cada operação.

A conversa de proposta acontece depois de um diagnóstico rápido — eu preciso entender o estágio da sua operação, o ICP, o ticket médio e o que você quer atingir nos próximos 90 dias para recomendar o caminho certo.

Se quiser ter essa conversa, me chama agora ou me manda mensagem. A conversa é sem compromisso.
```

---

### "Não tenho alguém que feche, então o CAÇADA não resolve."

```
Exato. E foi honesto em reconhecer isso.

O CAÇADA pressupõe que existe alguém que consegue conduzir R1 e fechar.

O caminho mais inteligente primeiro é você — ou alguém do time — dominar o roteiro de R1 que montamos aqui. Sistema Comercial Assistido pode ajudar nisso.

Quando o closer estiver operando, aí a gente conversa sobre volume.
```

---

## Notas de instrução

- Tom ao longo do upsell: consultor, não vendedor. Gabs encaminha, não empurra.
- Não usar linguagem de urgência artificial ("últimas vagas", "só hoje").
- O encaminhamento honesto por estágio é o diferencial. Quem não está pronto para CAÇADA precisa ouvir isso — e vai confiar mais por causa disso.
- A oferta certa para o estágio errado faz o cliente fracassar e culpar a APEX.
- Duração estimada do bloco de upsell: 15–20 minutos.
- Após o script, abrir para conversas individuais ou agendamento de diagnóstico.
