# Diagnóstico Rápido da Situação Atual

## Objetivo

Este diagnóstico serve para identificar, antes do workshop começar, onde a máquina comercial da software house está mais frágil.

Responda com honestidade. O objetivo não é parecer maduro. O objetivo é descobrir qual parte do sistema precisa ser construída primeiro.

---

# Como preencher

Para cada afirmação, dê uma nota de 0 a 2:

- **0:** não existe ou acontece muito mal.
- **1:** existe parcialmente, mas sem consistência.
- **2:** existe, é usado e funciona com clareza.

Some os pontos no final de cada bloco.

---

# 1. Oferta e posicionamento

| Critério | Nota |
|---|---:|
| Sabemos explicar em uma frase clara o que vendemos. | |
| Nossa oferta resolve uma dor de negócio, não apenas uma demanda técnica. | |
| Temos clareza sobre qual serviço/produto queremos priorizar. | |
| Nossa comunicação diferencia a empresa de outros fornecedores técnicos. | |
| Temos provas, cases ou argumentos que sustentam a promessa. | |

**Subtotal Oferta:** ___ / 10

## Sinais de alerta

- Vendemos "desenvolvimento sob demanda" de forma genérica.
- O cliente pede orçamento antes de entender valor.
- A conversa vira comparação de hora, prazo e preço.
- O dono precisa explicar tudo pessoalmente para a venda fazer sentido.

# 2. ICP e qualificação

| Critério | Nota |
|---|---:|
| Sabemos quais segmentos têm mais fit com nossa entrega. | |
| Sabemos reconhecer um lead ruim antes de perder muito tempo. | |
| Temos critérios mínimos de orçamento, autoridade, necessidade e urgência. | |
| Conseguimos classificar leads por prioridade. | |
| O time sabe dizer "não" para oportunidades sem fit. | |

**Subtotal ICP:** ___ / 10

## Sinais de alerta

- Toda oportunidade parece boa no começo.
- A empresa aceita qualquer projeto para não perder receita.
- Leads sem decisor avançam demais no funil.
- A proposta é enviada para quem ainda não demonstrou necessidade real.

# 3. Demanda e aquisição

| Critério | Nota |
|---|---:|
| Temos pelo menos um canal previsível de geração de oportunidades. | |
| Não dependemos exclusivamente de indicação. | |
| Temos mensagens ou conteúdos conectados a dores reais do ICP. | |
| Sabemos quais canais geram leads melhores. | |
| Existe rotina semanal de aquisição comercial. | |

**Subtotal Demanda:** ___ / 10

## Sinais de alerta

- O pipeline depende do humor da indicação.
- A empresa posta conteúdo, mas não gera conversa comercial.
- O outbound é feito apenas quando a agenda seca.
- Não existe clareza sobre qual canal priorizar.

# 4. Conversão e reunião comercial

| Critério | Nota |

| Existe critério claro para saber quando enviar proposta. | |
| As principais objeções têm respostas preparadas. | |

**Subtotal Conversão:** ___ / 10

## Sinais de alerta

- A reunião vira apresentação de portfólio.
- O cliente sai pedindo "manda uma proposta" cedo demais.
- A proposta é enviada sem dor, impacto ou decisor claros.
- Objeções são respondidas no improviso.

# Interpretação

## 0 a 15 pontos - Comercial no improviso

A empresa ainda depende muito do dono, de indicação e de esforço pontual. Antes de buscar escala, precisa organizar oferta, ICP e processo mínimo.

## 16 a 30 pontos - Base parcial, execução inconsistente

Existem algumas peças, mas elas ainda não formam sistema. O workshop deve ajudar a conectar oferta, demanda, qualificação e follow-up.

## 31 a 40 pontos - Máquina em formação

A empresa já tem partes importantes funcionando, mas ainda precisa padronizar, medir e melhorar a previsibilidade.

## 41 a 50 pontos - Base comercial madura

A empresa já tem estrutura. O foco deve ser lapidação, escala, melhoria de conversão e possível entrada em uma operação mais avançada.
