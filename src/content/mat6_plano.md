# 8. Próximo passo — mês 2

Com base no resultado dos 30 dias, qual é o próximo passo mais inteligente?

## Opção 1 — Continuar executando sozinho

Faz sentido quando:

- A operação está em Lapidação ou Escala.
- Os indicadores estão dentro do esperado para o estágio.
- Existe disciplina de revisão semanal.

## Opção 2 — Sistema Comercial Assistido

Faz sentido quando:

- A base foi construída, mas o resultado ainda não apareceu.
- Existe dúvida de onde o processo está travando.
- Preciso de um olho externo para revisar abordagem, R1 e pipeline.

## Opção 3 — CAÇADA

Faz sentido quando:

- A oferta está validada.
- Existe um closer para conduzir R1 e fechar.
- O gargalo é volume de leads inbound, não operação.
