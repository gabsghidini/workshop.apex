# Checklist de Proposta e Sequência 8x8

## Objetivo

Definir quando enviar proposta e como acompanhar oportunidades depois da reunião sem depender de mensagens vazias.

---

# 1. Checklist antes da proposta

Enviar proposta apenas se:

- [ ] a dor está clara;
- [ ] o impacto foi discutido;
- [ ] existe decisor ou caminho até decisor;
- [ ] existe consciência de investimento;
- [ ] o escopo inicial faz sentido;
- [ ] o próximo passo foi combinado;
- [ ] há critério para decisão;
- [ ] o CRM está atualizado.

# 2. Quando não enviar proposta

Não enviar quando:

- [ ] o cliente só pediu preço;
- [ ] a dor está vaga;
- [ ] não existe decisor;
- [ ] não existe urgência;
- [ ] o escopo está confuso;
- [ ] o cliente não aceita diagnóstico;
- [ ] ainda não sabemos o que estamos tentando resolver.

## Mensagem para segurar proposta

```text
[Nome], pelo que temos até agora, eu ainda não recomendaria te mandar uma proposta fechada.

O risco seria transformar uma dor real em um escopo genérico.

Antes, precisamos validar [ponto pendente]. Aí sim conseguimos propor um caminho com mais critério.
```

# 5. Regras

Nunca enviar:

- "Conseguiu ver?"
- "Alguma novidade?"
- "Passando para lembrar."
- "Fico no aguardo."

Toda mensagem precisa ter:

- contexto;
- valor;
- critério;
- pergunta clara;
- ou encerramento elegante.
