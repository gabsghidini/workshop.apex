# Checklist de Fit e Red Flags

## Objetivo

Criar critérios práticos para decidir se um lead deve avançar, ser nutrido ou ser desqualificado.

Esse checklist deve ser usado no primeiro contato, na qualificação e antes de aceitar uma reunião ou enviar proposta.

---

# 1. Green flags

Marque os sinais que indicam bom fit.

## Dor e contexto

- [ ] O lead descreve um problema operacional específico.
- [ ] O problema afeta tempo, dinheiro, escala, controle ou risco.
- [ ] A dor já gerou tentativa anterior de solução.
- [ ] O problema impacta mais de uma pessoa ou área.
- [ ] Existe consequência clara se nada mudar.

## Autoridade e decisão

- [ ] O decisor está na conversa.
- [ ] O contato tem acesso direto ao decisor.
- [ ] A área impactada participa da discussão.
- [ ] Existe clareza sobre quem aprova o projeto.

## Investimento

- [ ] O lead entende que resolver exige investimento.
- [ ] Já existe verba ou abertura para discutir faixa de investimento.
- [ ] O cliente compara valor e impacto, não só preço.
- [ ] O projeto tem potencial de ticket adequado.

## Urgência

- [ ] Existe prazo, meta, expansão, risco ou pressão interna.
- [ ] O lead sabe explicar por que isso importa agora.
- [ ] O problema está piorando.
- [ ] A empresa já perdeu tempo tentando contornar.

## Entrega

- [ ] O cliente tem equipe ou responsável para participar.
- [ ] Existe acesso a informações mínimas.
- [ ] O escopo pode ser priorizado em etapas.
- [ ] O cliente valoriza diagnóstico antes de execução.

---

# 2. Yellow flags

Sinais que exigem cuidado antes de avançar.

- [ ] O lead tem dor, mas não tem urgência.
- [ ] O contato parece influenciador, não decisor.
- [ ] O cliente ainda está "só pesquisando".
- [ ] Não existe faixa de investimento clara.
- [ ] O problema parece importante, mas não crítico.
- [ ] O cliente quer entender tudo por mensagem.
- [ ] A empresa já teve experiência ruim com fornecedor anterior.
- [ ] O projeto depende de aprovação futura.
- [ ] O escopo parece grande demais e pouco priorizado.

## Ação recomendada

- aprofundar diagnóstico;
- validar decisor;
- entender custo do problema;
- não enviar proposta cedo;
- nutrir se não houver urgência.

---

# 3. Red flags

Sinais que indicam desqualificação ou pausa.

- [ ] Quer apenas "um orçamento rápido".
- [ ] Compara diretamente com freelancer ou hora barata.
- [ ] Não sabe explicar o problema.
- [ ] Não existe decisor identificado.
- [ ] Não existe urgência.
- [ ] Não existe capacidade de investimento.
- [ ] Quer escopo fechado sem diagnóstico.
- [ ] Pede muita coisa antes de qualquer avanço real.
- [ ] Não quer envolver a área responsável.
- [ ] Não aceita processo de diagnóstico.
- [ ] O projeto parece ruim para margem ou reputação.
- [ ] O cliente já demonstra comportamento abusivo na venda.

## Ação recomendada

- desqualificar com respeito;
- indicar caminho mais simples, se fizer sentido;
- registrar motivo no CRM;
- não insistir.

---

# 4. Decisão de avanço

Use este critério:

## Avançar para reunião

O lead deve ter:

- dor real;
- decisor ou acesso ao decisor;
- consciência de investimento;
- urgência ou motivo claro;
- potencial de boa entrega.

## Nutrir

O lead deve ir para nutrição quando:

- tem fit, mas não tem urgência;
- tem dor, mas não tem decisor;
- ainda está educando a própria necessidade;
- pode virar oportunidade no futuro.

## Desqualificar

O lead deve ser desqualificado quando:

- não tem dor relevante;
- não tem fit com a entrega;
- quer apenas preço;
- não tem capacidade de investimento;
- tende a virar projeto ruim.

---

# 5. Frase de desqualificação elegante

```text
[Nome], pelo que você trouxe agora, eu não recomendaria avançarmos para uma proposta fechada.

O risco seria transformar uma necessidade ainda pouco clara em escopo técnico e isso normalmente gera desalinhamento.

Minha sugestão é vocês primeiro validarem [ponto pendente]. Se isso virar prioridade, faz sentido retomarmos com um diagnóstico mais estruturado.
```
