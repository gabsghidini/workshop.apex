# 5. Compromisso de execução

O workshop não funciona se virar apenas consumo de conteúdo.

Durante a imersão, meu compromisso é:

- [ ] preencher os exercícios antes do próximo encontro;
- [ ] tomar decisões mesmo com informação incompleta;
- [ ] escolher um ICP prioritário;
- [ ] escolher uma oferta central;
- [ ] testar pelo menos uma mensagem real;
- [ ] montar ou ajustar o CRM;
- [ ] registrar aprendizados;
- [ ] revisar o plano no final do Dia 2.
